# Tom and Jerry
Tom is chasing you. RUN!!!!

# How to play this with Unity
Clone the whole repository, and select the scene "Tom and Jerry" (Assets\Scenes\Tom and Jerry.unity) in Unity with the version of 6000.3.23f1

# How to play the game with Client
Download the zip file "Tom and Jerry.zip" and unzip it in your computer. After you unziped it, go into the folder and select "Tom and Jerry.exe", that is out game. =)
